# AI Bootcamp — Complete Curriculum

A comprehensive AI/ML bootcamp covering the full spectrum from foundational machine learning concepts to advanced LLM engineering, deep learning, and computer vision. This program spans **31 days** of structured instruction with hands-on notebooks, slide decks, and projects.

---

## Program Overview

| Phase | Days | Focus |
|-------|------|-------|
| **Foundations** | 1–10 | AI/ML concepts, EDA, model training & evaluation |
| **LLM Engineering** | 11–17 | Large Language Models, APIs, RAG, multi-modal AI |
| **AI Agents** | 18–21 | Agentic frameworks, OpenAI Agents SDK, LangGraph |
| **LLM Fine-Tuning** | 22–25 | Fine-tuning frontier & open-source LLMs, dataset generation |
| **Deep Learning** | 26–27 | Neural networks, backpropagation, CNNs |
| **Computer Vision** | 28–31 | Image processing, video analysis, YOLO, final project |

---

## Curriculum Breakdown

### Phase 1 — AI & ML Foundations (Days 1–10)

| Day | Topic |
|-----|-------|
| Day 1 | What AI Really Is — demystifying AI, types of intelligence, real-world applications |
| Day 2 | How Machine Learning Actually Learns — supervised/unsupervised learning, training loops |
| Day 3–4 | Exploratory Data Analysis (EDA) & Model Training — pandas, feature engineering, sklearn |
| Day 5 | Model Evaluation Metrics — classification metrics (accuracy, precision, recall, F1), regression metrics (RMSE, R²) |
| Day 6–7 | Model Validation — cross-validation, overfitting/underfitting, bias-variance tradeoff |
| Day 8–9 | Choosing the Right AI Approach & Design Trade-offs — problem framing, ML vs. rule-based vs. deep learning |
| Day 10 | Core AI Domains & Industry Use Cases — NLP, CV, time-series, recommender systems |

---

### Phase 2 — LLM Engineering (Days 11–17)

| Day | Topic |
|-----|-------|
| Day 11 | Introduction to LLMs — what they are, frontier vs. open-source models, running models locally with Ollama, OpenAI API basics |
| Day 12 | Chat Completions API — transformer architecture deep dive, multi-step LLM applications, prompt engineering |
| Day 13 | Multi-modal AI — vision-language models, building a multi-modal assistant |
| Day 14 | RAG (Retrieval-Augmented Generation) — vector databases, embeddings, document retrieval pipelines |
| Day 15 | Advanced RAG & Knowledge Graphs — hybrid search, re-ranking, structured retrieval |
| Day 16 | LLM Application Architecture — production patterns, caching, evaluation, building a Career Agent |
| Day 17 | Agentic AI Foundations — tool use, function calling, agent loops, planning & memory |

---

### Phase 3 — AI Agents (Days 18–21)

| Day | Topic |
|-----|-------|
| Day 18 | OpenAI Agents SDK — building autonomous agents, handoffs, guardrails |
| Day 19 | Multi-Agent Systems — agent orchestration, parallel agents, tracing & observability |
| Day 20 | Multi-Model Orchestration & Deep Research Agent — using multiple providers (Gemini, DeepSeek, Grok), structured outputs, building a production research agent |
| Day 21 | LangGraph — stateful agent workflows, graph-based execution, human-in-the-loop |

---

### Phase 4 — LLM Fine-Tuning (Days 22–25)

| Day | Topic |
|-----|-------|
| Day 22 | Fine-Tuning Frontier LLMs — LoRA, PEFT, fine-tuning GPT-4 class models via API |
| Day 23 | Open-Source LLM Fine-Tuning — fine-tuning Llama, Mistral, Qwen locally with Unsloth/HuggingFace |
| Day 24 | Fine-Tuning Showdown — comparing frontier vs. open-source fine-tuning approaches, evaluation strategies |
| Day 25 | Synthetic Dataset Generation — generating high-quality training data with LLMs |

---

### Phase 5 — Deep Learning (Days 26–27)

| Day | Topic |
|-----|-------|
| Day 26 | Deep Learning Fundamentals — neural network architecture, forward/backpropagation, activation functions, PyTorch basics |
| Day 27 | Deep Learning Part 2 — CNNs, batch normalization, dropout, transfer learning |

---

### Phase 6 — Computer Vision (Days 28–31)

| Day | Topic |
|-----|-------|
| Day 28 | Image Processing Foundations — pixels, color spaces, OpenCV, basic operations |
| Day 29 | Core CV Techniques — edge detection, filtering, thresholding, contour detection, feature extraction |
| Day 30 | Video Analysis & Object Tracking — background subtraction, optical flow, tracking algorithms |
| Day 31 | Deep Learning for CV & Deployment — YOLO object detection, activity recognition, packaging & deploying a model |

> **Final Project:** Build a Computer Vision pipeline to automatically calculate the **turnaround time of an airplane** from airport surveillance video footage.
